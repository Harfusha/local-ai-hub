MCP response estimates overlap the input-token accounting and must not be added to input tokens. Each agent had one failing test run before its successful run. Both produced equivalent integer arithmetic and input checks, but their test suites differ; passing these tests does not prove equivalent coverage for every input.

An additional narrow analysis of the retained structured MCP results found 45 nonblank source-line occurrences in `context` and `git_diff`, of which 13 exactly matched a previously observed line. This line-based estimate excludes repeated metadata, partial lines and envelope overhead, can count coincidental identical source lines, and is not an exact count or a bound on all repeated tool-result tokens. It is not a savings measurement.
