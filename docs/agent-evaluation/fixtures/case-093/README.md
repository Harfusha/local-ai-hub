# Fixture 093

`python prepare.py <nová-složka>` vytvoří nezávislý Git repozitář a skutečný konflikt mezi commity agent-a a agent-b. Cíl a příklady jsou v `PLAN.md`; `CHECKPOINT.md` popisuje simulovaný výchozí stav. Složka nesmí existovat. Pro hodnocení skutečného pokračování po přerušení musí provozovatel navíc provést a zaznamenat skutečné přerušení vlastního testovaného agenta; samotný seed jej nedokazuje. Po řešení ověř čerstvé testy, obě změny a stav merge. Nepoužívej produkční checkout.
