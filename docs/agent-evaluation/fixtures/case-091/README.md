# Fixture 091

Nová kopie pro každý běh; backend a frontend jsou disjunktní write scopes. Vyžaduje Python 3.11+ a Node.js podporující `--experimental-strip-types` (ověř před během). `oracle_091.py` je společný integrační oracle; výchozí seed musí selhat. Připravené scope nedokazují skutečnou delegaci ani integraci agentů.
