# Fixture 090

Zkopíruj složku do samostatného dočasného pracovního adresáře a agentovi předej pouze `zadani.md`. Oracle záměrně není součástí zadání dostupného agentovi před řešením; při slepém běhu jej zpřístupni až pro ověření. Server váže pouze 127.0.0.1 na náhodný volný port a nemá persistentní stav. Nejde o produkční Hub ani autentický doklad jeho běhu. `oracle_090.py` očekává nejprve chyby původního kontraktu; výsledek zaznamenej zvlášť od hodnocení opravené kopie.
