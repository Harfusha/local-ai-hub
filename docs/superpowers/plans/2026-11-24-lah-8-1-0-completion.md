## Review Focus (Top Failure Modes to Guard Continuously)

1. Silent fallback/false-green masks (skipped CI jobs, unconditional coverage step, cached pytest results, empty collection).
2. Epistemic provenance leakage (`llm_draft` stored as `deterministic-stub`, Laya self-predictions logged as gold ground truth, heuristic speedups labeled as measurements).
3. Unbacked/in-place state mutation (`create_backup=False` in setup migrations/embedding resets, cleanup deleting unverified backups by prefix).
4. Scope/confinement & identity bypasses (symlink/junction escapes, bag-of-words Laya cache cross-project hits, loopback assumed to authenticate process identity).
5. Resource/GPU conflicts (parallel LLM runs bypassing 1-slot / 12 GB VRAM cap, `embedding_space_rebuild_required` loop without recovery).
