# Native desktop replaces the web dashboard

The former `/dashboard` browser UI has been retired. The legacy CLI command `python tools/hubctl.py dashboard` now opens the native Rust desktop. Use `python tools/hubctl.py desktop` for the preferred name.

See [Native desktop](DESKTOP.md) for setup and operation and [migration evidence](DESKTOP_PARITY.md) for current coverage and remaining release gates. HTTP and MCP APIs are retained.
