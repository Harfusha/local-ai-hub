## 1. Performance Optimization Suite (F01–F24 / T0–T12)

- **T1 / F01 (Watcher Configuration Cache):** Eliminated repeated Git subprocesses (`git rev-parse`) on rejected filesystem events by caching effective project extension signatures. 1,000 unrecognized filesystem events execute in < 35 ms (< 0.04 ms per event) with 0 extra processes spawned.
- **T2 / F14 (Response Budget Readability):** Compacted response envelopes adaptively for constrained token budgets (128–3,500 tokens). Eliminates empty success shells and preserves minimal actionable task/record summaries with explicit artifact recovery pointers.
- **T3 / F02 (JSON and Token Budget CPU Acceleration):** Integrated `orjson` fast-path with streaming fallback for NaN/Infinity floats and >64-bit integers. Delivers **13.5× CPU throughput speedup** (0.71 ms vs 9.54 ms on 50 KiB payloads) with 100% byte parity.
- **T4 / F08 (Scoped Memory Candidate Windows):** Filtered candidate retrieval windows by canonical repository scope and provenance before `LIMIT` evaluation, eliminating foreign-scope candidate starvation.
- **T5 / F06 (Embedding Cache Batching):** Replaced one-by-one SQLite transactions with batched `get_many`/`set_many` operations across L1 RAM and persistent L2 disk cache.
- **T6 / F10 & F11 (Incremental SQL Batch Scoping):** Scoped CodeIndex metadata updates and Preprocessor step-hash card linking to touched batch paths (`WHERE path IN (...)`), eliminating full-table scans on keystroke saves.
- **T7 / F03 (SimHash Native Acceleration):** Integrated native Cython kernel (`src/local_ai_hub/native_kernels.py`) for contiguous uint64 buffer voting. Delivers **277× pure kernel speedup** and **92–94% whole-workflow time reduction** on Windows CI, with 100% bitwise parity and seamless graceful Python fallback.
- **T8 / F04 (Path Resolution Caching):** Added bounded thread-safe path resolution cache (`_resolved_paths`), reducing Windows `GetFinalPathNameByHandle` syscalls by **94.6%** on warm searches.
- **T9 / F09 (Token-Overlap Fallback Streaming):** Replaced unconstrained `fetchall()` with cursor streaming into a bounded top-k min-heap, reducing peak heap memory spikes to O(limit).
- **T10 / F12 (Context Backend Deadline and Cancellation):** Propagated `deadline` and `cancel_event` into RAG chunk batch scanning and model rerankers, immediately aborting execution upon caller timeout.
- **T11 / F17–F19 & F22 (Evidence-Bound Performance Verdicts):** Measured AST cold indexing (69.5% native CPython parse), Telemetry SQL (0.54 ms indexed query, 0.005 ms warm cache), Windows subprocess creation (19.7 ms CreateProcess overhead vs 205 MB/s stream throughput), and MCP residency (45 MB peak RAM, 0.0% idle CPU) to verify that rewriting these modules in Rust/Cython would introduce FFI risk without meaningful latency reduction.
- **T12 / T0 (Reproducible Measurement & Statistical Acceptance):** Implemented `tools/benchmark_native_candidates.py` supporting the 1,000-independent-pair tail statistical acceptance gate emitting canonical `perf_candidate.v1` records.

## 2. Cross-Platform Process Cleanup & Reliability

- **Linux Command Process Cleanup:** Resolved pre-existing Ubuntu process cleanup probe failure by verifying process group vacancy via `os.killpg(pid, 0)` before confirming termination, ensuring normal completed commands correctly report `cleanup_unconfirmed: False`.
- **Windows Process Tree Isolation:** Maintained strict Windows Job Object kill-on-close handles with pointer-sized types and suspension resume barriers.
- **macOS Canonical Temporary Roots:** Ensured temporary directories are strictly resolved once to avoid symlink alias mismatch (`/private/var/folders` vs `/var/folders`).
