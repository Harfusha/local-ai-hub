## Contracts an extraction must preserve

- Auth and tenant gate: `_require_authorized` first validates Host/origin, resolves admin action, checks `_authorized`, audits admin authorization, enforces tenant binding, then tenant rate limit (`:1463-1498`). Outcomes include 401 unauthorized, 503 if required admin audit is unavailable, 403 from tenant binding, and 429 with `retry_after_seconds` when rate-limited. A route helper must not bypass or reorder this gate.
- JSON body gate: `_read_json` requires Content-Length, enforces configured max body size, accepts `application/json` and `application/merge-patch+json`, decodes UTF-8 JSON, requires an object (`:1500-1567`). Request body errors include 411 missing length, 413 too large, 408 timeout, 415 wrong content type, and 400 malformed/non-object JSON. Generic dispatch serializes `RequestBodyError` with its status plus `terminal=true,retryable=false` (`:3050-3054`).
- Raw body exception: bundle import uses `_read_body`, not `_read_json`; preserve raw bytes, configured limit, query target, fingerprint/idempotency, recovery journal behavior, and import error mapping.
- Mode/admin exception: `/api/admin/mode` has its own strict JSON validation and stable `error_code=invalid_mode_request`; its 423 response is retryable during active inference/resource cleanup.
- Dispatch outcomes: unknown path returns 404; `QueueFullError` maps to 429 retryable; `ModelUnavailableError` maps to 503 retryable; invalid value/type/body maps to 400 terminal/nonretryable; lookup errors map to 404 terminal/nonretryable; client disconnect closes trace with 499; unexpected exceptions log and attempt 500 (`:5113-5137`).
