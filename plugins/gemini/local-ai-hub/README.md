# Local AI Hub for Gemini CLI

Gemini CLI extension with shared Hub skills, contextual instructions, stdio MCP, native SessionStart/BeforeTool/AfterTool hooks, and Policy Engine confirmation rules for sensitive coordinator actions. Those host prompts add consent friction; Hub-side ownership, consent, and evidence checks remain authoritative. Install from this directory with `gemini extensions install <path-to-this-directory>` and review the extension trust prompt. Setup-managed global Gemini settings and this extension are alternative MCP/hook routes; do not enable both copies.
